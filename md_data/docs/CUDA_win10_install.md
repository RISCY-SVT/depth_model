Для работы таких модулей, как PyTorch с поддержкой GPU, необходимо установить подходящую версию CUDA и (при необходимости) cuDNN, а также убедиться, что драйверы NVIDIA обновлены. Ниже приведён пошаговый план установки CUDA на Windows 10:

---

### 1. Проверьте Совместимость Вашего GPU

- Убедитесь, что ваша видеокарта поддерживает CUDA. Список поддерживаемых GPU можно найти на [странице NVIDIA CUDA GPUs](https://developer.nvidia.com/cuda-gpus).

---

### 2. Обновите Драйверы NVIDIA

- Перейдите на [NVIDIA Driver Downloads](https://www.nvidia.com/Download/index.aspx) и скачайте последнюю версию драйвера для вашей видеокарты.
- Установите драйвер, следуя инструкциям установщика. Перезагрузите систему, если требуется.

---

### 3. Скачайте и Установите CUDA Toolkit

- Перейдите на [страницу загрузки CUDA Toolkit](https://developer.nvidia.com/cuda-downloads).
- Выберите:
  - **Операционную систему:** Windows  
  - **Архитектуру:** x86_64  
  - **Версию Windows:** Windows 10  
  - **Тип установки:** Экземплярный установщик (local installer) или network installer
- Скачайте установщик и запустите его.
- В процессе установки выберите «Express» (рекомендуется) или «Custom», если хотите изменить параметры.
- По окончании установки установщик настроит переменные среды (например, PATH, CUDA_PATH).
- Check path in %PATH% variable:
    `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.8\libnvvp;C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.8\bin;`

---

### 4. (Опционально) Установка cuDNN

Если вы планируете использовать модули, требующие cuDNN (например, при сборке некоторых версий TensorFlow или при ручной сборке PyTorch):
- Перейдите на [страницу cuDNN](https://developer.nvidia.com/cudnn) (требуется регистрация).
- Скачайте версию, совместимую с вашей версией CUDA.
- Распакуйте архив и скопируйте файлы (библиотеки, заголовки и файлы документации) в соответствующие каталоги CUDA Toolkit (обычно это папки `bin`, `include`, `lib` внутри каталога CUDA).

---

### 5. Проверьте Установку

Откройте командную строку (cmd.exe) и выполните команды:

- **Проверка версии nvcc (компилятора CUDA):**
  ```cmd
  nvcc --version
  ```
  Это должно показать информацию о версии CUDA.

- **Проверка драйвера:**
  ```cmd
  nvidia-smi
  ```
  Эта команда выведет информацию о вашей видеокарте и версии драйвера.

---

### 6. Настройка Python и PyTorch

Многие современные сборки PyTorch поставляются с включенной поддержкой CUDA (встроенные CUDA runtime библиотеки). Обычно достаточно установить PyTorch с нужной версией CUDA, например:
  
```bash
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu118
```

Здесь `cu118` означает, что используется CUDA 11.8. Если у вас установлена другая версия CUDA, выберите соответствующий пакет. На официальном [сайте PyTorch](https://pytorch.org/get-started/locally/) есть удобный генератор команд для установки, где можно указать версию CUDA.

---

### Дополнительные Замечания

- Если вы планируете использовать другие фреймворки (например, TensorFlow), убедитесь, что версии CUDA и cuDNN совместимы с выбранной версией фреймворка.
- В некоторых случаях установка CUDA Toolkit в систему не обязательна для использования PyTorch, так как официальные колеса уже содержат все необходимые библиотеки. Однако для разработки собственных проектов или сборки модулей может понадобиться системная установка CUDA.

---

Следуя этим шагам, вы установите CUDA на Windows 10 так, чтобы её можно было использовать в Python-модулях, таких как PyTorch и другие, требующие вычислительных возможностей GPU.
